# Inter-se Opero

## How do I install these formulae?

`brew install inter-se/opero/<formula>`

Or `brew tap inter-se/opero` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "inter-se/opero"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
